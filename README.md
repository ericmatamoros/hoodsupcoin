# $HOODSUP

The official pixel-art launch site for $HOODSUP and the myth of the Midnight Guild.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
npm test
```

## Deployment

The project is a standard Next.js app and is ready for Vercel. Pushes to the connected GitHub repository deploy automatically through the existing Vercel integration.

Final token supply, distribution, liquidity, fees, chain and contract details are intentionally marked as sealed until they are confirmed for launch.
